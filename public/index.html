How it works

Two roles, both NVIDIA Nemotron models served by Nebius Token Factory, and one deterministic referee.

Attacker: Nemotron 3 Ultra

The hard, creative job. It rotates six techniques (system notice, pre-authorization, output hijack, fake tool call, step splitting, urgency) and is told exactly how far its last attempt got. Reasoning is off: with it on, Ultra refused 25–54% of attempts in a 60-trial run; with it off, 0%.

Agent under test

Nemotron 3.5 Lightning by default, at $0.06 / $0.24 per million tokens, or Nano 30B or Ultra 550B to compare. It runs a real tool-calling loop on its ordinary task. The injection is the only thing that changes between attempts.

Referee: code, not a model

The verdict comes from the agent's actual tool calls: did a secret leave to an outside address, did money move, was a file deleted? An injection cannot talk its way past a state check.

Test your own agent

Bring your Python agent's orchestration and tool policy through the local adapter. Model calls stay metered on Nebius; tools run against synthetic state. The included confirmation-policy example shows how to test a defence. Adapter quickstart ↗

Guardrails on this demo

Live runs require a judge code. Each run has a budget stop and an attempt limit. Recorded runs remain available when live runs are paused and are always labelled. The current deployment uses per-instance spend counters; a shared store is required for global caps and public runs.

Turncoat is defensive security research: you test only agents you own, on fully synthetic fixtures. No real person, account, secret or file is involved. MIT licensed. Built for the Nebius × NVIDIA Global AI Hackathon.
